# Password Proof Generator - PoC

Proof of Concept for Zero-Knowledge Password Proof using Soundness Layer integration.

## Features
- Password input interface
- ZK Proof generation simulation
- Proof verification
- Copy to clipboard functionality

## How to Run
1. Clone this repository
2. Open `index.html` in a web browser
3. Enter a password and click "Generate Proof"
4. Copy or verify the generated proof

## PoC Demonstration
This demonstrates:
- ✅ Basic web interface for password input
- ✅ Proof generation mechanism
- ✅ Proof verification system
- ✅ User-friendly interface
